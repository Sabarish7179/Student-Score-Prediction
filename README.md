# Student Score Prediction using Machine Learning

## Project Description

This project predicts a student's exam score based on the number of hours studied using Linear Regression.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Visualization
4. Train-Test Split
5. Linear Regression Model
6. Prediction
7. Model Evaluation
